# Andrea Zavatta — Software Engineer Portfolio

---

## 🌐 Live Website

The portfolio is live and deployed on GitHub Pages. Open the site at:

👉 **[https://andreazavatta.github.io](https://andreazavatta.github.io)**  

---

## ⚡ Tech Stack

- **Framework:** [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler:** [Vite](https://vite.dev/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/) + Custom SVG brand marks
- **Deployment:** GitHub Pages via GitHub Actions

---

## 🚀 Deployment

The site is continuously deployed to GitHub Pages using the automated workflow in [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml). Any push to the `main` branch triggers an automated build and publishes the distribution to the `gh-pages` branch.
